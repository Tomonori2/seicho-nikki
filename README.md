# 🌱 すくすく日記

**写真とその日の声を残すだけで、AIが子どもの成長日記を書いてくれるアプリです。**

👉 **今すぐ使う： https://tomonori2.github.io/seicho-nikki**

子育て中は毎日いそがしくて、日記を続けるのはむずかしいもの。
「すくすく日記」は、写真を撮って、今日のできごとをひとこと話す（または書く）だけ。
あとはAIが、あたたかい成長日記に仕上げてくれます。

---

## ✨ できること

- 📷 **今日の一枚**を残す（写真を見て、AIが日記にいかします）
- 🎤 **話すだけで入力**（音声でメモできます）
- 🎙 **その日の子どもの声を録音**（「ママ！」のひと声が、数年後の宝物に）
- ✍️ **AIが日記を代筆**（子どもの名前・月齢入りで、自然な日記に）
- 🔄 **気に入らなければ書き直し**（文のふんいきも「やさしく／たのしく／みじかく」から選べます）
- 🔊 **声の思い出を続けて聞く**（古い順に子どもの声だけを再生。成長を耳で振り返れます）
- 🎵 **振り返りBGM**（日記を読み返すときに、そっと音楽を流せます）
- 📖 **月ごとに整理**して読み返せる
- 💾 **バックアップの書き出し／読み込み**（機種変更のお引っ越しにも）

---

## 🔒 プライバシーについて

- 写真・声・日記などの思い出は、**すべてお使いの端末の中だけ**に保存されます（サーバーには送りません）。
- 日記の作成にAIを使うときだけ、写真とメモがGoogleのGeminiに送られます（写真を送らない設定も選べます）。
- **APIキーはあなた自身のものを使う方式（BYOK）**。キーも端末の中だけに保存され、外には出ません。

大切な思い出データは端末内にしかないので、ときどき「バックアップを書き出す」でファイルに保存しておくと安心です。

---

## 🚀 使い方（かんたん3ステップ）

1. **無料のGemini APIキーを用意**
   [Google AI Studio](https://aistudio.google.com/app/apikey) でログイン →「Create API key」→ `AIza…` で始まる文字をコピー
2. アプリを開いて、右上の **🔑 APIキー設定** に貼り付ける
3. 写真をとる・今日のできごとを話す →「✍️ 日記を書いてもらう」を押すだけ

## 🛠 技術メモ

- HTML1ファイル完結（HTML / CSS / JavaScript すべて内蔵）
- PWA対応（スマホのホーム画面に置けます・オフラインでも起動）
- 保存：localStorage（設定）＋ IndexedDB（写真・声つき日記）
- AI：Google Gemini（ブラウザから直接呼び出し・BYOK方式）
